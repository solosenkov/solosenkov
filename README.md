## Кейсы

### Tolik Tours — цифровая автоматизация тур-агентства
- Сайт, CRM и Telegram-бот под ключ
- Самое популярное тур-агентство в Нячанге
- Срок: 2 дня
- Результат: бот принимает заявки 24/7, CRM ведёт учёт расписания

### RikiTiki — маркетплейс детских услуг
- Веб-платформа на Next.js + Supabase
- Лучший детский маркетплейс во Вьетнаме
- Срок: 1 месяц
- Результат: многоязычный интерфейс (RU/EN/VN), система бронирования

### Lendoso — AI-аудит лендингов
- SaaS-платформа для автоматического QA
- Node.js, Playwright, OpenRouter API
- Результат: время проверки лендинга сократилось с 2 часов до 2 минут

### CRM для частных заказчиков
- Множество систем учёта клиентов, заявок и записей
- Интеграции с Telegram, WhatsApp, платёжными системами, 1С
